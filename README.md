
# ESTUDANDO PYTHON

Lista de exercícios de Python resolvida em aula do SESI SENAI no curso Técnico em Desenvolvimento de Sistemas.

## TECNOLOGIAS

- Python
- VS Code

## LISTA DE NOVE EXERCICIOS

1. Média de três números
2. Conversor de temperatura
3. Identificação de número par ou ímpar
4. Cálculo de fatorial
5. Verificador de ano bissexto
6. Verificação de número positivo ou negativo
7. Comparação de dois números
8. Verificação de idade
9. Classificação de triângulos

## EXEMPLOS

- Condicionais
- Estrutura de repetição `for`
- Soma de números

## COMO EXECUTAR

É necessário ter o Python instalado no computador.

1. Abra o terminal na pasta do projeto.
2. Escolha o exercício que deseja executar.
3. Utilize o comando correspondente ao arquivo.

### EXEMPLOS DE EXECUÇÃO

Para executar o exercício de média:

```py EXERCICIOS/01_media.py```


## Objetivo

Praticar os conceitos fundamentais da linguagem Python, desenvolvendo a lógica de programação por meio de exercícios e exemplos realizados em aula.
